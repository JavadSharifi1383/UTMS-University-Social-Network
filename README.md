# UTMS: University Social Network

A 3-phase Advanced Programming final project that evolves a complex C++ Object-Oriented system into a fully functional University Management and Social Networking platform.

## 📌 Overview
UTMS (University Teaching Management System) combines academic administration (course offerings, TA recruitment) with social features (posts, connections, notifications). The project demonstrates architectural evolution from a core CLI application to a web-integrated system.

## 🚀 Key Features
* **Phase 1 (Core & CLI):** Robust OOP architecture, CSV data parsing (Students, Professors, Courses), and handling REST-like CLI commands (GET, POST, PUT, DELETE).
* **Phase 2 (Academic Workflows):** Implementation of Teaching Assistant (TA) application forms, course-specific communication channels, and automated notification triggers.
* **Phase 3 (Web Integration):** Migration of the C++ logic to serve a graphical user interface, enabling browser-based interaction with the core system.

## 🛠️ Tech Stack
* **Language:** C++20
* **Architecture:** Object-Oriented Programming (OOP), Modular Multi-file Structure
* **Build System:** Make
